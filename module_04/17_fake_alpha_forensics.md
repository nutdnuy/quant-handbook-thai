# บทที่ 17: 【ข้อควรระวังในภาคปฏิบัติ】กรณีศึกษาการตรวจสอบแฟกเตอร์ลวง (Fake Factor) ที่ทำให้หน้าแตก

> **เป้าหมายหลักของบทนี้**:  
> เชี่ยวชาญ "การตรวจสอบระดับนิติวิทยาศาสตร์และการตรวจสอบต่อต้านการฉ้อฉล" ที่เข้มงวดที่สุดของสถาบัน Quant ฝั่ง Buy-side ระดับชั้นนำก่อนการตรวจรับและนำแฟกเตอร์ (Factor) ขึ้นใช้งานจริง เจาะลึก 3 รูปแบบ Alpha ปลอมที่อันตรายถึงชีวิตและพบบ่อยที่สุด: **การแฝงตัวของมูลค่าตลาดหุ้นขนาดเล็กพิเศษ (Size Parasitism)**, **ผลตอบแทนส่วนเกิน (Excess Return) ปลอมจากการเคาะซื้อหุ้นชนเพดาน (Limit-up) ไม่ได้ (Unexecutable Limit-up Orders)** และ **การพังทลายของความจุกลยุทธ์ตามกลุ่มมูลค่าตลาดย่อย (Capacity Illusion)** พร้อมเขียนระบบตรวจสอบแฟกเตอร์ลวงแบบอัตโนมัติเต็มรูปแบบ และสร้างรายงานแฟ้มประวัติการตรวจสอบความเสี่ยงที่เป็นมาตรฐาน

## 1. ทำไมแฟกเตอร์ที่ "ดูสวยหรู" มักพังยับเยินอย่างรวดเร็วในการเทรดจริง (Live Trading)?

ในชีวิตการทำงานประจำวันของนักวิจัย Quant สิ่งที่น่าหดหู่ที่สุดคือการ Backtest ใน Jupyter Notebook จนได้ "แฟกเตอร์ขั้นเทพ" ที่มี Excess Return รายปี 35%, Rank IC เกินกว่า 0.10 และแบ่งชั้นได้อย่างสมบูรณ์แบบ แต่พอเอาขึ้น Live Trading จริง มูลค่าสินทรัพย์สุทธิไม่เพียงแต่ไม่เพิ่มขึ้นเลย ซ้ำร้ายยังแพ้ดัชนีชี้วัดอย่างต่อเนื่องและหนักหน่วง

```
หน้ากากจำแลง 3 ชั้นของ Alpha ปลอม
├── หน้ากากที่ 1: การแฝงตัวตามสไตล์มูลค่าตลาด (หลงคิดว่าเบี้ยประกันความเสี่ยงสภาพคล่องของหุ้น Micro-cap คือ Alpha ในการเลือกหุ้น)
│     └── วิธีการคัดแยก: บังคับทำ OLS Residual Regression กับค่า Log ของมูลค่าตลาดหมุนเวียน แล้วสังเกตว่า IC ของค่าเศษเหลือบริสุทธิ์ร่วงดิ่งหน้าผาหรือไม่
├── หน้ากากที่ 2: กับดักผู้รอดชีวิตจากการไล่ราคาชนเพดาน (ทึกทักเอาเองว่าจะสามารถ Match คำสั่งได้เต็มจำนวนในหุ้นที่ Limit-up แข็งสนิท)
│     └── วิธีการคัดแยก: กำหนดเงื่อนไขสภาพคล่องที่เทรดได้จริง ณ เวลาส่งคำสั่ง และบังคับให้คำสั่งที่ไม่ได้รับการจับคู่คงค้างเป็นเงินสดในบัญชี
└── หน้ากากที่ 3: ล้มเหลวสิ้นเชิงกับหุ้นขนาดใหญ่ (แฟกเตอร์มีพลังพยากรณ์อันน้อยนิดเฉพาะในหุ้น Micro-cap 300 ตัวที่เล็กที่สุดในตลาดเท่านั้น)
      └── วิธีการคัดแยก: แยกทดสอบอิสระใน 3 ดัชนีย่อย ได้แก่ CSI 300, CSI 500 และ CSI 1000
```

## 2. กรณีศึกษาที่ 1: การทดสอบการแทรกซึมของการแฝงตัวตามมูลค่าตลาด (Size Parasitism Test)

### 2.1 กลไกที่ซ่อนเร้น
แฟกเตอร์จำนวนมาก (เช่น ความผันผวนของปริมาณการซื้อขายขนาดย่อม, ขนาดของการกลับตัว, สภาพคล่องต่ำของ Amihud) ผิวเผินแล้วมีค่า Rank IC ที่สูงมาก แต่ผลตอบแทนเบื้องหลังถึง 80%~100% เกิดขึ้นเพียงเพราะตัวมัน**มีความสัมพันธ์เชิงลบทางคณิตศาสตร์กับมูลค่าตลาดโดยธรรมชาติ** (กล่าวคือ หุ้นมูลค่าตลาดขนาดเล็กจะมีค่าแฟกเตอร์นี้สูงกว่าโดยธรรมชาติ) หากช่วงเวลาตัวอย่างตรงกับช่วงตลาดกระทิงของหุ้น Micro-cap พอดี แฟกเตอร์นี้จะสร้าง Excess Return จากการเลือกหุ้นที่หลอกตาอย่างมหาศาล

### 2.2 แผนการผ่าชันสูตรระดับนิติวิทยาศาสตร์
ในทุกภาคตัดขวาง (Cross-sectional) ของแต่ละวันซื้อขายในอดีต ให้บังคับทำ Cross-sectional OLS Regression เทียบกับค่า Log ของมูลค่าตลาดหมุนเวียน:

$$f_{i, t} = \alpha_t + \beta_t \ln(\text{MarketCap}_{i, t}) + \epsilon_{i, t}$$

คำนวณ Rank IC ของลำดับค่าเศษเหลือบริสุทธิ์ $\boldsymbol{\epsilon}_t$ โดยนิยาม**อัตราการหดตัวของ Style IC (Style IC Drop Ratio)**:

$$\text{DropRatio} = 1.0 - \frac{\text{Rank IC}(\boldsymbol{\epsilon})}{\text{Rank IC}(\mathbf{f})}$$

- **เส้นตายการควบคุมความเสี่ยงของ Buy-side**: หาก $\text{DropRatio} > \mathbf{60\%}$ แสดงว่าโดยเนื้อแท้แล้วแฟกเตอร์นี้เป็นเพียงหุ่นเชิดของการเปิดรับความเสี่ยงสไตล์มูลค่าตลาด ห้ามนำเข้าคลังในฐานะแฟกเตอร์ Alpha อิสระโดยเด็ดขาด!

## 3. กรณีศึกษาที่ 2: การทดสอบสภาพคล่องที่เทรดได้จริงของการไล่ราคาชนเพดาน (Tradability Test)

### 3.1 ช่องโหว่การจับคู่คำสั่งที่อันตรายถึงชีวิต
หลายกลยุทธ์ในการ Backtest มีสมมติฐานว่า: ขอเพียงแค่หุ้นตัวนั้นปิดตลาดชนเพดาน (+10%) ตอนเปิดตลาดช่วงเช้าตนเองจะต้องซื้อได้เต็มจำนวนด้วยราคาเปิดอย่างแน่นอน
- **ความเป็นจริงของโครงสร้างจุลภาคของตลาด**: หุ้นที่สามารถพุ่งชนเพดานต่อเนื่องได้จริงนั้น ในช่วงประมูลราคาเปิดเวลา 09:25 น. ฝั่ง Bid ช่องที่ 1 จะมีคำสั่งซื้อตั้งขวางรอคิวไว้เป็นแสน Lot แล้ว คำสั่ง Limit Order ของสถาบันและรายย่อยจะตกไปอยู่ท้ายสุดของแถวคิวมหาศาล **ความน่าจะเป็นที่คำสั่งจะได้รับการจับคู่คำสั่ง (Matching) ซื้อขายจริงเท่ากับ 0 อย่างเคร่งครัด**!
- **การบิดเบือนข้อมูลอย่างร้ายกาจของโค้ดมือสมัครเล่น**: หากนำหุ้นที่ไม่สามารถซื้อได้ตัดออกจาก Universe หุ้นที่เลือกโดยตรง แล้วนำสัดส่วนพอร์ตที่เหลือไปเฉลี่ยให้กับหุ้นตัวอื่นที่ซื้อได้ แท้จริงแล้วนี่คือการ**บังคับปรับโครงสร้างพอร์ตลงทุน ซึ่งเป็นการปกปิดความเสียหายที่แท้จริงจากการที่เงินทุนตกรถและนอนนิ่งไม่ได้ทำกำไร**!

### 3.2 กฎการลงบัญชีเงินสดที่เข้มงวดของ Buy-side
สมมติว่าในวัน $t$ กลยุทธ์ได้สร้างรายชื่อหุ้น Top Candidate แบบถ่วงน้ำหนักเท่ากันตามสัญญาณ โดยแต่ละตัวได้รับการจัดสรรสัดส่วนเงินทุนเป้าหมาย $w_i = \frac{1}{K}$:
- หากหุ้น $i$ เปิดตลาดในวันถัดไปชนเพดานสนิทจนไม่สามารถซื้อได้ **เงินทุนเป้าหมายก้อนนี้จะต้องถูกบังคับคงไว้ในบัญชีเงินสด (ผลตอบแทนของวันนั้นเป็น 0)**!
- ผลตอบแทนคาดการณ์ล่วงหน้าแบบถ่วงน้ำหนักที่แท้จริงของพอร์ตการลงทุน จะต้องคำนวณอย่างเคร่งครัดเป็น:
  $$R_{\text{realistic}} = \sum_{i \in \text{Filled}} w_i \cdot r_{i, t+1} + \sum_{j \in \text{Unfilled}} w_j \cdot 0.0$$
- กำหนดนิยาม**อัตราส่วนการลดทอนกำไรจากสภาพคล่องที่เทรดได้จริง (Tradability Haircut Ratio)**:
  $$\text{Haircut} = \frac{R_{\text{ideal}} - R_{\text{realistic}}}{R_{\text{ideal}}}$$
- **เส้นตายการควบคุมความเสี่ยงของ Buy-side**: หาก $\text{Haircut} > \mathbf{40\%}$ แสดงว่า Excess Return ทางทฤษฎีส่วนใหญ่ของแฟกเตอร์ถูกสร้างขึ้นบน "ภาพลวงตาของการชนเพดานที่ซื้อไม่ได้" เมื่อนำไป Live Trading ย่อมแพ้ตลาดอย่างรุนแรงแน่นอน!

## 4. กรณีศึกษาที่ 3: การตรวจสอบความจุตามกลุ่มมูลค่าตลาดย่อย (Capacity Robustness)

แฟกเตอร์ Alpha ที่ยอดเยี่ยม ต้องมีความสามารถในการส่งผ่านและคงประสิทธิภาพอย่างมั่นคงในระดับสภาพคล่องที่แตกต่างกัน:
1. **กลุ่มหุ้นบลูชิปขนาดใหญ่ (มูลค่าตลาด Top 30%, เทียบเคียง CSI 300)**: ทดสอบขีดความสามารถในการรองรับเงินทุนระดับหมื่นล้าน
2. **กลุ่มหุ้นขนาดกลางแกนหลัก (มูลค่าตลาด Mid 40%, เทียบเคียง CSI 500 / CSI 1000)**: ทดสอบขีดความสามารถหลักในการสร้าง Excess Return ของแฟกเตอร์
3. **กลุ่มหุ้นขนาดเล็กพิเศษท้ายแถว (มูลค่าตลาด Bottom 30%)**: สังเกตว่าแฟกเตอร์พึ่งพาเฉพาะเกมเก็งกำไรที่มี Turnover สูงลิ่วหรือไม่

- **เกณฑ์การคัดเลือกเข้าพอร์ตของ Buy-side**: ในกลุ่มย่อยหุ้นขนาดใหญ่ Rank IC ของแฟกเตอร์ต้องมีค่าเป็นบวกอย่างน้อย ($\text{IC}_{\text{large}} > \mathbf{0.015}$) หากในกลุ่มหุ้นขนาดใหญ่ค่า IC กลายเป็นศูนย์อย่างสิ้นเชิง หรือพลิกกลับด้านกลายเป็นลบ แสดงว่าแฟกเตอร์นั้นไม่สามารถรองรับเงินทุนขนาดใหญ่ของฝั่ง Buy-side ได้เลย

## 6. สรุปบทนี้และ Checklist การส่งมอบภาพรวมโมดูลที่ 4

มาถึงตรงนี้ **โมดูลที่ 4: ระบบการประเมินแฟกเตอร์ (Factor) ระดับอุตสาหกรรมและการคัดกรอง Alpha เทียม** ได้ถูกสร้างขึ้นอย่างครบถ้วนสมบูรณ์ทั้ง 4 บทหลัก!

### ตารางตรวจสอบตนเองระดับทองคำสำหรับการส่งมอบคลังแฟกเตอร์ฝั่ง Buy-side (Delivery Checklist):
- [ ] **พลังการทำนายของ IC ได้มาตรฐาน (บทที่ 14)**: ค่าเฉลี่ย Rank IC มีเสถียรภาพอยู่ที่ $0.03 \sim 0.06$, ค่าสถิติทดสอบ $t$ แบบ Robust ของ Newey-West HAC มากกว่า 3.0, กราฟ IC สะสมปรับตัวเพิ่มขึ้นอย่างต่อเนื่องและมีเสถียรภาพ;
- [ ] **ความเป็น Monotonic อย่างเคร่งครัดและผลตอบแทนส่วนเกิน (Excess Return) ฝั่ง Long (บทที่ 15)**: มูลค่าสินทรัพย์สุทธิของแต่ละกลุ่มย่อยทั้งแบบ 5 ส่วนหรือ 10 ส่วนเพิ่มขึ้นอย่างเคร่งครัด ($\text{MonoScore} \ge 0.80$), สัดส่วนผลตอบแทนจากฝั่ง Long คิดเป็นสัดส่วนมากกว่า $40\%$, กำจัดกับดักฝั่ง Short ได้อย่างเด็ดขาด;
- [ ] **ต้นทุน Turnover ควบคุมได้ (บทที่ 16)**: ความสัมพันธ์ในตัวเองของอันดับแฟกเตอร์อยู่ในระดับสูง, ค่า Information Half-life ยาวนานกว่ารอบการปรับพอร์ต (Rebalance), ค่า Sharpe Ratio สุทธิในแต่ละสถานการณ์หลังหักความเสียดทานการซื้อขายแบบไป-กลับยังคงเป็นบวก;
- [ ] **การตรวจสอบเชิงนิติวิทยาศาสตร์เพื่อป้องกันการหลอกลวง (บทที่ 17)**: ผ่านการทดสอบปรสิตมูลค่าตลาด (IC ลดลง $< 60\%$), ผ่านการทดสอบแบบทะลุทะลวงกรณีชนเพดาน (Limit-up) ซื้อไม่ได้ (อัตราส่วนลด $< 40\%$), และใน Universe หุ้นขนาดใหญ่ระดับหัวแถว ค่า IC ยังคงเป็นบวกอย่างมีนัยสำคัญ.

ตั้งแต่โมดูลถัดไป เราจะเข้าสู่: **โมดูลที่ 5: การเรียนรู้ของเครื่อง (Machine Learning) และวิศวกรรมการผสานฟีเจอร์** อย่างเป็นทางการ เพื่อเรียนรู้วิธีการใช้การตรวจสอบไขว้แบบแบ่งกลุ่มอนุกรมเวลา (Time-series) ป้องกันข้อมูลรั่วไหล (PurgedGroupTimeSeriesSplit), โมเดลจัดอันดับภาคตัดขวาง (Cross-sectional) ด้วย LightGBM/CatBoost และการวิเคราะห์ความสามารถในการอธิบายผลด้วย SHAP เพื่อหลอมรวมชุดแฟกเตอร์เดี่ยวคุณภาพสูงเหล่านี้ให้กลายเป็นเครื่องยนต์ทำนาย Alpha ที่ทรงพลัง!
